# Chrome Web Store — submission checklist

Everything you need to publish A11y Companion, in order. Files referenced here
are generated by this repo's tooling (`npm run build` and `npm run assets`).

## 0. One-time setup

- [ ] Create a developer account at the [Developer Dashboard](https://chrome.google.com/webstore/devconsole)
      and pay the **one-time $5** registration fee.

## 1. Host the privacy policy (required for `<all_urls>`)

The store requires a public privacy-policy URL because the extension uses a broad
host permission.

- [ ] Enable **GitHub Pages** for the repo (Settings → Pages → Build from a
      GitHub Action). The included workflow `.github/workflows/pages.yml`
      publishes the `demo/` folder.
- [ ] Confirm these load:
  - Live demo: `https://luis-avalos1.github.io/accessibility-plugin/`
  - Privacy:   `https://luis-avalos1.github.io/accessibility-plugin/privacy.html`

> If your GitHub username/repo differs, update the URLs in `store/listing.md`,
> `store/privacy-data-disclosures.md`, and `demo/demo.js`.

## 2. Build the package

- [ ] `npm run build` → produces `dist/a11y-companion-<version>.zip` with
      `manifest.json` at the archive **root** (the build verifies this).
- [ ] Each new upload needs a higher `version` in `extension/manifest.json`.

## 3. Generate / refresh store assets (optional — already committed)

- [ ] `npm run assets` re-runs the demo verifier, re-records the video, and
      regenerates screenshots + promo tiles.

## 4. Create the item

- [ ] **Add new item** → upload `dist/a11y-companion-<version>.zip`.
- [ ] **Store listing** tab — paste from `store/listing.md`:
  - [ ] Item name, Summary, Detailed description
  - [ ] Category: **Accessibility** · Language: **English (US)**
  - [ ] Upload **screenshots** `store/screenshots/01..05-*.png` (1280×800)
  - [ ] (Optional) promo tiles from `store/promo/`
  - [ ] Store icon is taken from the package (`icons/icon128.png`)
- [ ] **Privacy practices** tab:
  - [ ] Single purpose + permission justifications → `store/permissions-justification.md`
  - [ ] Data-usage checklist + certifications → `store/privacy-data-disclosures.md`
  - [ ] Privacy policy URL (step 1)

## 5. Submit

- [ ] Set distribution (Public / Unlisted) and submit for review.
- [ ] Expect extra scrutiny / a longer first review because of `<all_urls>`;
      a clarification email is normal — reply with the justifications above.

## 6. After it's live

- [ ] Set `STORE_URL` in `demo/demo.js` to the published listing URL so the
      demo's "Add to Chrome" buttons point at it; redeploy Pages.
- [ ] Update the install links in `README.md` and `store/listing.md`.
